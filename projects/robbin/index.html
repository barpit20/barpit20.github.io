Robbin - The Robotic Bin
Tags

Robotics, Engineering Design

When

Jan - April 2017

Team Size

4

Tools

Arduino, C

A robotic dustbin to minimise spilt over garbage. Our bot picks up scattered garbage around it, compresses the garbage inside it and sends a message to the authorities when it is ready to be emptied. This was achieved using 5 servo motors, 3 DC motors and a GSM Module all controlled using an Arduino Mega. I also created the logo and the poster of the project.
